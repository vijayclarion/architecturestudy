## 🎯 How to Use These

```
2 WEEKS BEFORE EXAM:
─────────────────────────────────────────────
Read each cheat sheet. Quiz yourself.
Notice gaps → go back to the detailed notes.

1 WEEK BEFORE EXAM:
─────────────────────────────────────────────
Do active recall — close the sheet, explain it
out loud. Whiteboard the decision trees.

DAY BEFORE EXAM:
─────────────────────────────────────────────
Just read these. Don't try to learn new material.
Trust your prep.

DURING EXAM:
─────────────────────────────────────────────
For scenario questions, mentally walk down the
right decision tree. The exam often gives you
4 options where 1 is correct AND obvious if
you know the tree. The other 3 are plausible
red herrings.
```
